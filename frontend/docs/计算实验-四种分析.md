# 计算实验的四种分析：观察 / 干预 / 反事实 / 机制

> 依据：薛霄, 于湘凝, 周德雨, 彭超, 王晓, 周长兵, 王飞跃. 计算实验方法的溯源、现状与展望. 自动化学报, 2023, 49(2): 246−271. doi: 10.16383/j.aas.c220092
> 核心命题：计算实验的本质，是把"反事实"算法化。

## 0. 总纲：一张因果阶梯

论文把四种分析统一挂在 Pearl 的三层因果阶梯上——"对应于 Pearl 的三层因果关系（关联、干预和反事实推理），实验分析方法包括动态网络分析、事件链分析以及行为机制分析"。更准确地说：

> 观察 = 关联层；干预 = 干预层；反事实 = 反事实层；机制分析 = 横切三层、把黑箱打开的那把钥匙。

- 证据强度：观察 < 干预 < 反事实。
- 建模成本：观察 < 干预 < 反事实。
- 机制分析不占某一层，它把宏观现象接到微观行为规则上，是让上面三层"可解释、可追溯"的底座，也是设计反事实实验的依据。

## 1. 观察分析（第 1 层：关联）

- 回答的问题："X 和 Y 是不是一起在变？系统现在处于什么状态？"
- 性质：只描述模式、相关、演化趋势，**不下因果结论**。
- 落地方式：对应论文的宏观分析，用动态网络刻画系统，链路为
  **驱动力 → 运行 → 状态 → 溯源 → 响应**。
  - 运行：社会网络 / 信息网络 / 价值网络三层异质网络。
  - 状态：生态侧（多样性、层次性）、网络侧（规模、路径长度、结构洞、健壮性、可靠性）、经济侧（竞争、公平、有效性、风险/安全、信用、偏好）。
- 定位：**唯一不需要先有假设、先选策略**的一步，负责把现象和候选影响因素"看得见"。
- 边界：看到"补贴高 → 产能高"只是相关，背后可能有第三方同时影响两者（混杂 / 后门路径），因此结论应标记为"关联级证据"。

## 2. 干预分析（第 2 层：干预）

- 回答的问题："**如果我动手改变 X（do(X)），Y 会怎么变？**"——主动施加，而非被动观察。
- 落地方式：对应中观的事件链分析，以及论文 2.2 的"干预机制"。真正去改人工社会的规则 / 参数 / 外部输入，跑仿真看输出。
- 干预可分三层：
  - Agent 模型：个体特征、行为规则；
  - 组织模型：群体交互方式、学习规则；
  - 社会模型：传播方式、均衡状态。
- 为什么强于观察：在虚拟世界里**真正切断后门路径**，并能做到实物实验做不到的随机化、重复、可控、可区组。这正是计算实验"精确可控"的价值。
- 闭环要求：**施加干预 → 观测输出 → 与目标/偏好比对 → 判断可行性 → 迭代完善**（论文图 9）；干预不是一次性的，需随环境变化持续调整。
- 典型产物：A/B 策略对比、干预前后分布差异、策略评分。

## 3. 反事实（第 3 层）

- 回答的问题："**已经发生的这件事，如果当时 X 不一样，结果会怎样？**"——针对一个**特定已发生结果**做回溯推演。
- 与干预的本质区别：
  - 干预是**前瞻**的、对整个人工社会重新施加、得到一个**分布**（"如果改 X，一般会怎样"）；
  - 反事实是**回溯**的、锁定同一个体 / 同一世界（"这次具体结果，若当时 X 不同会怎样"），因此必须先**反推隐状态（abduction）**——这一步只有反事实才有。
- 正式三步：**反推（abduction）→ 干预 do(X)（action）→ 前向预测（prediction）**。
- 工程做法：做成**成对世界**——事实世界（基线）+ 反事实世界（改过 X），两条世界共用同一随机种子，保证"只有干预不同"。
- 边界：反事实属最高层，**不能靠拟合度自证**，需由结构验证 / 机制分析支撑置信度；结果要给置信区间 / 分布，而非单点。

## 4. 机制分析（打开黑箱，支撑反事实）

- 回答的问题："**为什么会这样？干预是通过什么中间环节起作用的？**"
- 地位：论文原话——"机制分析是计算实验的核心"。
- 与"模型拟合分析"的对立：
  - 拟合分析只追求**宏观现象的重合率**（用神经网络 / RL 学一个行为映射），统计上相关，但那套"行为规律"现实中可能根本不存在；
  - 机制分析**切进演化的每个环节**，还原"**影响 → 作用 → 涌现**"的因果链条。
- 具体链条（论文图 16）：**宏观情景1 → 个体行为取向（信念/愿望/意图 BDI）→ 行为生成规则 + 主体间互动规则 → 宏观涌现情景2**。每一步都要有可观测的中间量，否则退化成黑箱拟合。
- 与反事实的绑定：机制分析提出"哪条规则 / 哪个意图在起作用"的假设，反事实实验负责**验证**（屏蔽某条规则、替换某个行为取向，看涌现结果是否按机制预测变化）。故论文说"行为机制分析可设计各种反事实实验"。
- 形式化：量化节点因果可用**概率因果模型**（Pearl）；路径系数要看 `do()` 效应，而非普通相关系数。

## 5. 对照表

| 维度 | 观察分析 | 干预分析 | 反事实 | 机制分析 |
| --- | --- | --- | --- | --- |
| 因果阶梯 | 关联（第1层） | 干预（第2层） | 反事实（第3层） | 横切，支撑反事实 |
| 典型问句 | X 和 Y 一起变吗 | 改 X 会怎样（前瞻） | 当时若改 X 会怎样（回溯） | 为什么/怎么起作用 |
| 是否动手 | 否 | 是 | 是（且需反推隐状态） | 拆解到规则层 |
| 结果形态 | 相关/模式/趋势 | 干预前后的分布 | 同一世界的对照结果 | 因果链条 + 中间量 |
| 数据要求 | 现成数据即可 | 需可施加干预的模型 | 需可反推个体隐状态 | 模型可拆解到规则层 |

## 6. 与 SCnet 页面的对应

- `ExpAnalysis_Observe.vue`：定位"关联级"，标注证据等级，避免把观察当因果。
- `CausalInference.vue` / `ExpAnalysis_Intervention.vue`：走 `do()`，闭环迭代，策略分三层。
- `CounterfactualExperiment.vue`：做"事实 / 反事实成对世界 + 反推隐状态"，输出分布而非单点。
- `ExpAnalysis_Mechanism.vue`：走"BDI → 规则 → 涌现"因果链条，每一步配可观测中间量。

## 7. 常见误区

- 把观察当因果：相关 ≠ 干预。
- 把干预当反事实：前瞻分布 ≠ 同一结果的回溯。
- 把拟合当机制：重合率高 ≠ 机制对。
- 拿单次结果当结论：结果应是分布，真实世界只是一个样本；需重复运行 + 显著性检验。
