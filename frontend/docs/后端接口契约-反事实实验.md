# 反事实实验后端接口契约（P1 / P2）

> 依据：薛霄, 于湘凝, 周德雨, 等. 计算实验方法的溯源、现状与展望. 自动化学报, 2023, 49(2): 246−271.
> 论文要求计算实验遵循**随机化、重复、区组化**三原则，且"实验结果是一个分布，真实世界只是一个样本"。
> 前端已实现"事实/反事实成对世界 + 同种子 + 区组重复"，本契约列出后端需要支持的最小集合。

## 1. 现有端点（前端已在用，无需新增即可跑通）

| 用途 | 方法 / 路径 |
| --- | --- |
| 提交运行 | `POST /SCnet/runExperiment` |
| 队列历史 | `GET /queue/history?limit=N` |
| 实验详情 | `GET /SCnet/supplyChain/experiments/{experimentId}` |
| 实验报告 | `GET /SCnet/supplyChain/experiments/{experimentId}/report` |
| 指标分布 | `GET /SCnet/supplyChain/experiments/{experimentId}/distribution` |
| 反事实推理（单点，因果推断页） | `POST /SCnet/supplyChain/experiments/{experimentId}/counterfactual-reasoning` |

## 2. 请求契约（`POST /SCnet/runExperiment` 新增字段）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `world_kind` | string | 是 | `factual`（事实世界，报告基线参数）或 `counterfactual`（反事实世界，干预后参数） |
| `seed` | integer | 是 | 本次运行的随机种子；**同一区组内两个世界取相同值** |
| `random_seed` | integer | 否 | `seed` 的兼容别名，二者数值一致 |

其余字段沿用现状：`scenario`、`iterations`、`model`、`param_overrides`、`agent_node_configs`、`subtask_variable_configs`、`baseline_report`、`scenario_context`、`phase`、`source_page`、`user_goal`。

约束：
- 事实世界与反事实世界**除 `param_overrides` / `agent_node_configs` 外必须完全一致**（含 seed、轮次、初始条件）。
- 后端应**容忍并忽略**不认识的字段（如 `world_kind`），不得因此报错。

## 3. 批量运行契约（区组化）

前端对第 `i` 个区组（`i = 1..N`）提交 2 个任务：`factual(seed=base+i)` 与 `counterfactual(seed=base+i)`。

- 默认 `N = 5` → 一次反事实实验产生 `2N = 10` 个任务；`N` 可在界面调整（1–20）。
- 要求：
  1. 队列能同时容纳 `2N` 个任务，不丢任务；
  2. **单个任务失败不影响其它任务**（前端按成功组数汇总，n 不足时如实降级）；
  3. 同一 `seed` 的两次运行必须可复现（相同 seed + 相同初始条件 ⇒ 相同结果），这是"配对比较"成立的前提。

## 4. 回执契约（种子回执 —— 判断"同种子"是否真的生效）

实验详情或报告中需回显该次运行的 `seed`。前端已兼容以下任一字段名：

`seed` / `random_seed` / `randomSeed` / `parameters.seed` / `config.seed`

- 回执且等于该 run 的 `seed` → 前端显示「种子受控（后端已回执）」；
- 未回执 → 前端显示「种子已提交，待后端回执确认 / 未受控」，**不声称同种子生效**。

## 5. 分布返回（可选增强）

若后端能直接给出分布（而非前端跑 N 次），建议 `GET /SCnet/supplyChain/experiments/{id}/distribution` 返回：

```json
{
  "n": 30,
  "samples": [0.71, 0.73, 0.69],
  "mean": 0.71, "median": 0.71, "min": 0.69, "max": 0.73,
  "ci95": [0.695, 0.725]
}
```

前端策略：**后端给了就用后端的**；否则用"多次运行 + 自助法 95% CI + 配对符号检验"自行估计。

## 6. 可选：成对端点

若希望减少往返，可提供一次性提交一对世界的端点，返回配对结果：

```
POST /SCnet/supplyChain/counterfactual/paired
{ "base_seed": 12345, "repeats": 5, "baseline_params": {...}, "intervention": {...} }
→ { "pairs": [ { "seed": 12346, "factual_experiment_id": "...", "counterfactual_experiment_id": "..." } ] }
```

前端当前用现有端点组合实现，此端点非必需。

## 7. 前端降级行为（已实现，无需后端配合）

- 后端未回执 seed → 面板标「未受控」；
- 单组失败 → 不阻断其余，按有效组数汇总；
- 全部失败 / 队列持续无响应超过 60 秒 → 回退合成分析，并明确标注（合成只有 n=1，不给效应量与显著性）。

## 8. 验收标准

1. 同一 `seed` 两次运行结果一致（可复现）；
2. 实验详情回执 `seed`；
3. 队列并发 `2N` 个任务无丢失；
4. 前端「成对世界」面板显示「种子受控」，并给出 `n` 组配对样本的差值 95% CI 与符号检验 p。

## 9. 前端交接契约（反事实引擎 → 复盘报告 EXreport）

反事实引擎产出「结论 + 分布 + 配对效应」后写入浏览器 `localStorage`，复盘报告按同一实验 id 读取。
这是纯前端交接，不新增后端接口；后端只需保证该实验 id 在 `GET /SCnet/supplyChain/experiments` 列表可见。

- 存储键：`scnet_counterfactual_report:{experiment_id}`
- 写入时机：成对世界全部落定后（前端 `finalizeWorldPair`）
- 读取时机：EXreport 解析出实验 id 后（`loadCounterfactualReport`，精确匹配，无「最新一条」兜底）
- id 归属：EXreport 用 `currentExperimentId` / `localStorage.selectedExperimentId` 解析实验 id，
  因此反事实页跳转报告页前，会先把同一个 id 写入 `selectedExperimentId`。

载荷字段：

```json
{
  "experimentId": "20261003_120000",
  "scene": "supply_chain",
  "savedAt": "2026-10-03T04:00:00.000Z",
  "seed": 12345,
  "seedControlled": true,
  "repeatCount": 5,
  "conclusion": "……",
  "effect": { "n": 5, "meanDifference": 0.13, "ci95": [0.05, 0.21], "pValue": 0.0625 },
  "distribution": { "mean": 0.742, "ci95": [0.701, 0.783], "n": 5 },
  "factualDistribution": { "mean": 0.612, "ci95": [0.58, 0.644], "n": 5 },
  "completionSamples": [0.71, 0.74],
  "factualSamples": [0.6, 0.61],
  "interventionDiff": [ { "key": "capacity_range", "from": [50, 100], "to": [80, 150] } ],
  "settledCounts": { "factual": 5, "counterfactual": 5 }
}
```

- `seedControlled`：`true / false / null`，表示「后端是否回执了同一个 seed」；EXreport 显示为「种子受控 / 未受控 / 待回执」。
- 完成率为 0–1 比率；EXreport 对 `> 1.5` 的值按百分数 ÷100 归一，两种口径都能读，且可重复归一不出错。
- 合成兜底 id（`synthetic_` 前缀）不写入交接：复盘报告只用真实后端实验 id 取数。

验收：跑完成对世界后点「生成复盘报告（含反事实结论）」，报告页出现「反事实实验结论」区块
（配对 n、两世界均值与 95% CI、差值 CI 与符号检验 p、干预变量清单），并在文本 / HTML / PDF 导出中一并出现。
